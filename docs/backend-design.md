# Backend: проект

Статус: черновик, решения приняты 2026-11-19.

## Решения
- **Стек:** Node.js (TypeScript) + Fastify, PostgreSQL, Docker Compose, nginx как обратный прокси.
- **Вход:** email + одноразовая ссылка (magic link). Паролей нет. Нужен SMTP для отправки писем.
- **Хостинг:** сервер OVH в ЕС, домен taalbrug.snapko.nl. Фронтенд остаётся одним `index.html`
  и ходит в `/api/*` на том же домене (без CORS).
- **Данные:** персональные данные учеников, в том числе беженцев. Требования AVG/GDPR:
  хранение в ЕС, шифрованный диск, регулярные бэкапы, минимум данных, удаление по запросу.

## Роли и права
Роли teacher/admin выдаются через `TEACHER_EMAILS` / `ADMIN_EMAILS` в окружении сервера (при входе). Роль, выданную вручную в базе, вход не понижает.

| Роль | Видит и делает |
|---|---|
| learner | свой прогресс, опубликованные уроки, сдаёт письменные работы |
| teacher | свои группы, посещаемость, конструктор уроков, оценка работ |
| admin | всё: группы, список ожидания, рахунки, пользователи |
| client | только агрегаты по своим группам (без имён учеников) |

Роль проверяется на сервере в каждом запросе. Фронтенд ничего не решает сам.

## Модель данных (черновик)
- `users` (id, email, name, role, lang, created_at)
- `login_tokens` (token_hash, user_id, expires_at, used_at): одноразовые, живут 15 минут
- `sessions` (id, user_id, expires_at): httpOnly cookie
- `clients` (id, name, type: gemeente|employer)
- `groups` (id, name, type, client_id, teacher_id, capacity, lesson_no)
- `memberships` (group_id, user_id, intake_level, current_level, attendance, online_hours)
- `waitlist` (id, name, email, level, time_pref, pay_pref, created_at)
- `course` (id=1, data JSONB, version, updated_by): курс целиком одним документом, у уроков `status` draft/live
  (нет статуса = live). Запись с `baseVersion`, при расхождении 409. Ученикам отдаются только опубликованные уроки.
- `progress` (user_id, data JSONB, updated_at): на этапе 2 весь учебный прогресс одним документом
  (`done`, `scores`, `known`, `fc`, `ex`, `cur`, `week`, `streak`; белый список, проверка форм, лимит 512 КБ).
  Позже, если понадобятся отчёты по урокам, разнесём в отдельные таблицы.
- `submissions` (id, user_id, lesson_id, item_idx, text, status new|done, grade 0..2, feedback, graded_by): одна работа на (ученик, урок, упражнение).
  Если курс уже на сервере, работа должна относиться к упражнению типа `write` в опубликованном уроке.
- `invoices` (id, client_id, description_nl/uk, amount, paid)

## API (первая версия)
- `POST /api/auth/request` (email), `GET /api/auth/verify?token=`, `POST /api/auth/logout`, `GET /api/me`
- `GET/PUT /api/me/progress`
- `GET /api/course`, `PUT /api/course` (teacher/admin)
- `GET /api/groups`, `PATCH /api/groups/:id/attendance`
- `GET/POST /api/submissions` (ученик видит свои, teacher/admin все), `PATCH /api/submissions/:id` (оценка, teacher/admin)
- `GET/POST /api/waitlist`, `POST /api/waitlist/:id/place`
- `GET /api/invoices`, `PATCH /api/invoices/:id`
- `GET /api/reports/:clientId` (агрегаты)

## Этапы
(этапы 1, 2 и конструктор уроков из этапа 3 сделаны; письменные работы сделаны: вход по ссылке; прогресс на сервере; фронтенд с окном входа и синхронизацией)
1. Каркас: Fastify + Postgres + миграции, вход по ссылке, `/api/me`, docker-compose, выкладка.
2. Прогресс учеников (`progress`, `known_words`, `flashcards`) вместо `localStorage`.
3. Конструктор уроков и письменные работы (teacher).
4. Группы, посещаемость, список ожидания, рахунки, отчёты для заказчиков.
5. Бэкапы, мониторинг, политика приватности, удаление данных.

# Воронка: тест уровня → бесплатная часть → оплата

Статус: решения приняты 2026-11-19. Этап 1 (тест уровня) и этап 2 (бесплатный/платный доступ, коды, paywall) реализованы; Mollie и отчёты для заказчиков ещё нет.

## Решения
- **Оплата:** разово за уровень (курс A1, затем A2 и т.д.). Подписки нет.
- **Бесплатно:** первый модуль целиком (сейчас Kennismaken: 6 уроков с тестом). Остальное видно в маршруте
  с замком, ценой и превью первого диалога.
- **Платежи:** Mollie (iDEAL, карты, Apple Pay), страница оплаты на стороне провайдера. Карточные данные к нам не попадают.
  Доступ открывается только по подтверждённому статусу платежа, который сервер сам запрашивает у Mollie.
- **Заказчики** (gemeente, работодатель) платят за учеников сами: коды и приглашения, оплата ученику не показывается.

## Путь пользователя
1. Лендинг → «Check je niveau»: тест без регистрации, 15–20 вопросов (mc, gap, listen, tf) по нарастающей сложности A0 → A2.
2. Результат: уровень, процент, рекомендованный модуль. Email просим здесь, вход по ссылке сохраняет результат.
3. Бесплатный первый модуль. Paywall мягкий и появляется после теста первого модуля (ученик уже втянулся).
4. Оплата уровня → доступ к модулям этого уровня.
5. Без тёмных паттернов: никаких таймеров и скрытой автооплаты, понятная цена, письма-напоминания (день 3 и 7).

## Данные (черновик)
- `placement_results` (id, user_id NULL до входа, session_token, level, score, answers JSONB, created_at)
- `modules.access` (`free` | `paid`) и `modules.level`: поля в документе курса, не отдельные таблицы
- `products` (id, level, price_cents, currency)
- `payments` (id, user_id, product_id, mollie_id, status, amount_cents, created_at, paid_at)
- `entitlements` (user_id, level, source: payment|client_code|manual, granted_at, client_id NULL)
- `access_codes` (code_hash, client_id, level, seats, used)

## Защита на сервере
`GET /api/course` для пользователя без доступа отдаёт платные уроки только с названием и длительностью, без `items` и контента.
`POST /api/submissions` и сохранение прогресса по платным урокам требуют доступа.

## Закон и налоги (проверить до запуска)
- Цифровой контент: 14-дневное право отказа. Перед оплатой нужно явное согласие на немедленный старт и подтверждение потери права.
- НДС на обучение (возможное освобождение зависит от статуса и регистрации): уточнить у бухгалтера.
- Счета/чеки, условия, политика приватности, возврат по запросу.

## Этапы
1. Тест уровня и рекомендация (без оплат).
2. Бесплатный/платный модуль, `entitlements`, доступ на сервере, paywall в интерфейсе. Доступ пока выдаётся вручную или кодом.
3. Mollie в тестовом режиме: платёж, вебхук, проверка статуса, выдача доступа.
4. Коды и места для заказчиков, отчёты.

## Тест уровня: как устроен (этап 1)
- **Алгоритм:** «лестница». Старт на сложности 2 (A1). Верно: сложность +1, неверно или «не знаю»: −1 (границы 0 и 5).
  Сложности 0–1 = A0, 2–3 = A1, 4–5 = A2. В банке 30 вопросов, по 5 на сложность (`backend/src/placement-bank.ts`).
- **Остановка:** от 8 до 14 вопросов; раньше при трёх ошибках подряд на самом лёгком уровне или трёх верных на самом сложном;
  от 8 вопросов, когда последние 4 вопроса лежат в диапазоне не шире одного уровня.
- **Оценка:** среднее сложностей последних 6 вопросов. Ниже 2 = A0, от 2 до 4 = A1, от 4 = A2.
  Ученик, проходящий уровень k и проваливающий k+1, колеблется между ними (среднее k+0.5), поэтому пороги 2.0 и 4.0, а не 1.5 и 3.5.
- **Сервер хранит вопросы и ответы.** Клиент получает по одному вопросу с перемешанными вариантами, верных ответов не видит.
  Состояние в `placement_sessions` (токен хранится хешем). Анонимный старт ограничен 30 в час на IP (в памяти процесса).
- **API:** `POST /api/placement/start`, `/resume`, `/answer` (с номером вопроса `n` против двойной отправки), `/claim` (после входа),
  `GET /api/me/placement`.
- **Курс:** результат (`S.placed`) открывает первый модуль своего уровня и все модули уровнем ниже, а «Продолжить» ведёт на него.
  Модули на следующих уровнях по-прежнему открываются тестом предыдущего модуля.
- **Кнопка «Check je niveau»** на лендинге и плашка на экране ученика показываются, только если доступен `/api`.

### Что нужно до запуска
- **Вопросы должен проверить преподаватель нидерландского** (грамматика, однозначность вариантов, уровень сложности).
  Рекомендуется калибровка на реальных учениках после запуска и расширение банка до 10+ вопросов на уровень.
- Озвучка в тесте использует голос браузера (`speechSynthesis`), качество зависит от устройства.

## Доступ к уровням (этап 2)
- **Правило:** модуль с `lvl: 'A0'` бесплатный, остальные требуют доступа к своему уровню. Поле модуля `access: 'free' | 'paid'` переопределяет.
  Модуль без `lvl` считается платным (безопасное значение по умолчанию).
- **Сервер:** `GET /api/course` для ученика без доступа отдаёт закрытые модули как оболочки (id, тип, название, минуты) с `locked: true`, без слов,
  упражнений и ответов. Сдача письменной работы в закрытом уроке: 403. Преподаватели и админы видят всё.
- **Выдача доступа:** `entitlements (user_id, level, source manual|code|payment)`.
  Админ: `POST/DELETE /api/admin/entitlements` (по email), `POST /api/admin/codes`, `GET /api/admin/codes`, `PATCH /api/admin/codes/:id` (отзыв).
  Ученик: `POST /api/me/redeem`, `GET /api/me/entitlements`.
- **Коды:** `TB-XXXX-XXXX` (без 0/O/1/I), в базе только хеш, показывается один раз при создании. Число мест, срок действия, отзыв.
  Повторный ввод тем же пользователем не занимает место. Подбор ограничен: 10 неудачных попыток в час на пользователя (в памяти процесса).
- **Интерфейс:** кнопка «Ontgrendel» у закрытых модулей, окно ввода кода, плашка после бесплатной части, панель «Toegang beheren» у админа.

### ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ перед запуском
Стандартный курс (`DEFAULT_COURSE`) целиком встроен в `index.html`, то есть платное содержимое лежит в исходном коде страницы и открыто всем.
Серверная защита работает для данных из API, но не для этого файла. Перед запуском нужно вынести содержимое платных модулей из `index.html`
(оставить только структуру/названия), загрузить курс на сервер через конструктор и открывать платное содержимое только через `GET /api/course`.
Пока этого не сделано, нельзя считать платный контент защищённым.

# Цены (решения 2026-11-19, цифры — гипотезы для проверки)

## Решения
- **Плательщики:** поровну розница и заказчики (gemeente, работодатели). Нужны и розничная цена уровня, и цена за место.
- **Розница:** доступная, заметно ниже университетского самообучения. Ориентиры рынка: RUG Online Dutch A1>A2 360 €, Babel A1→A2 группа от 550 €,
  Radboud 1 225 €, LOI 99 € в месяц; бесплатно: RUG intro, Karibu, NT2 TaalMenu. Цены нужно сверить с актуальными страницами.
- **Проверка преподавателем в розничную цену не входит.** Розничный тариф: уроки, упражнения, автопроверка.
- Цены в розницу показываются **с НДС**. Статус НДС для обучения уточнить у бухгалтера.

## Следствия
- **Письменные работы у розничных учеников.** Без преподавателя задание теряет смысл, если оставить его как «сдать на проверку».
  Для розницы: образец ответа и чек-лист самопроверки (как в упражнении «Nazeggen»), без кнопки «Inleveren bij docent».
  Проверку преподавателя получают: (а) ученики групп и места заказчиков, (б) покупатели платной проверки (позже, отдельным продуктом).
  Для этого у доступа нужен признак «с проверкой» (`entitlements.review boolean`), и сервер принимает работы на проверку только с ним.
- **Ученики живых групп** получают онлайн-часть без доплаты (в копирайте уже заявлено): админ выдаёт доступ при зачислении в группу.
  Их цена в `S.rev` (165–250 € за ученика в месяц) уже включает онлайн-часть.
- **Заказчики:** цена за место на уровень со скидкой за объём, коды с числом мест уже поддерживаются.

## Гипотезы цен (проверить на реальных затратах и на пользователях)
Предельные затраты розницы без проверки близки к нулю (комиссия платёжного сервиса и НДС), поэтому цена ограничена рынком, а не себестоимостью.
| Продукт | Гипотеза | Комментарий |
|---|---|---|
| A1, самостоятельно | 39–49 € | вход, ниже RUG на порядок; можно тестировать 39 против 49 |
| A2, самостоятельно | 49–59 € | больше содержимого и ценности |
| Пакет A1 + A2 | 79–89 € | небольшая скидка, подталкивает к покупке обоих |
| Место заказчика, один уровень | 25–35 € при 10+ местах | ниже розницы за объём; включает отчёты по группам |
| Проверка преподавателя (позже) | отдельным продуктом, по цене на единицу | считать от времени преподавателя |
Условия: 14 дней возврата, оплата разово, без автопродления.

## Что нужно уточнить
- Реальное время преподавателя на одну письменную работу и его ставка (для цены проверки).
- Статус НДС, регистрация обучающей деятельности.
- Нужна ли скидка для беженцев/по запросу (код со скидкой или бесплатное место за счёт заказчика).
